# Awaaz – Every Voice Matters

Awaaz is a calm, bilingual (English and Urdu) speech therapy web application designed to help children with speech and hearing disabilities practise communication skills at home.

It turns therapist-set lessons into daily home practice, interactive activities and learning games.

## Try Awaaz

**Live Demo:** https://maleehaimran.github.io/Awaaz/

**Source Code:** https://github.com/MaleehaImran/Awaaz

### How to use

1. Open the website in Google Chrome.
2. Select **Therapist Demo** or **Parent Demo**.
3. Sign in using the demo option.
4. Allow microphone access when requested.
5. Explore speech practice, live captions, games and progress reports.

## Features

- Bilingual English and Urdu interface.
- Therapist and parent demo access.
- Interactive speech practice.
- Microphone and speech recognition features.
- Live captions (Chrome support).
- Fun & Learn educational games.
- Progress reports.
- Accessibility options, including read aloud, dyslexia spacing and focus mode.

## Technology

- HTML5
- CSS3
- Vanilla JavaScript
- Web Speech API
- getUserMedia
- localStorage

No server or database required for the current demo.
